# Third-party reference material

The PDFs and ZIPs under `source/` are unmodified Texas Instruments downloads.
Their original copyright, Important Notice, disclaimers and other applicable
terms remain in force. The searchable files under `text/` are derived from
those PDFs and retain the same third-party status.

The root MIT license applies to original project material. It does not relicense
TI documents, design files, models, or linked third-party implementation code.
The archive is engineering reference material for development with TI products.
Preserve the original notices when using it and review applicable terms before
redistributing vendor artifacts.

[Provenance](source/provenance.json) identifies the official source URL, retrieved
payload, date, size and checksum of each archive item. ZIP member lists are
recorded without extracting or modifying their contents.

Official repository links in [source-code.md](source-code.md) identify their
licenses separately. In particular, GPL Linux source is a reference, not part
of this project's MIT implementation. If permissively licensed source is later
reused, retain its actual copyright and license notices as required.

Future packaging must exclude this reference archive from normal firmware and
library release packages unless there is an explicit, reviewed reason to include
particular material. No third-party source code is compiled by this workspace.
